# Product vision

## Owner direction

A personal, self-hosted board: no authentication, collaboration or SaaS.
Replace paid Miro. Future functions are driven by migrating a representative
board. This preserves the original owner direction recorded before these
portable product documents were introduced.

## Requirements recorded on 2026-10-30

The representative workflow includes link- and image-heavy boards. Requested
capabilities include efficient image previews, new URL capture without requiring
an already-saved item, nested frames, a subtle gray grid, richer text, a full-page
table view over the same data, and syntax-highlighted code blocks.

These are product requirements to refine against representative material and
pending screenshots, not implemented features or an approved execution order.
The [roadmap](ROADMAP.md) records proposed work; [architecture](ARCH.md)
distinguishes today's source from proposed designs. Migration discovery must
report losses in URLs, images, connectors, frames, geometry and relationships.
No real account access or board import is authorized by these documents.
